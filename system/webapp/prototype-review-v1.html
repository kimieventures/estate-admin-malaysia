Panduan Review

  1. 📝 Intake — isi maklumat kes (contoh: Muslim, tiada wasiat, harta ≤RM5 juta) → sistem klasifikasi laluan bercitation + anggaran fi + senarai semak norma
  2. ⚖️ Aliran Kes — lalui 11 pintu sebagai PASANGAN berperanan; cuba lulus pintu dengan peranan SALAH untuk nampak check & balance
  3. 🧮 Faraid — uji enjin pecahan (presets bercitation; semak jumlah = 1)
  4. 💰 Fi — estimator berasaskan jadual terverifikasi (P.U.(A) 194/2024, ARB rasmi, mahkamah)
  5. 🛡️ Norma — cuba paksa norma PERLU SAHKAN (akan DISEKAT)
  6. 🔐 Audit — rantaian hash session; cuba butang "Demo sabotaj" untuk nampak pengesanan pengubahan silam

Status Sistem

Prototaip ini ialah peringkat 2 urutan D-2 (dashboard + aliran + advisorial simulasi) berserta pandangan awal enjin logik (faraid + fi). Enjin munasakhat (berlapis), lejar kewangan, Q&A konsensus & backend bersepadah menyusul. Output agent di pintu ialah simulasi bercitation daripada repo ilmu (22+ fail, 1,277 sitasi).
