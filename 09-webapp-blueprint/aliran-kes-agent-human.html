Protokol Q&A Konsensus (P5)

  • Agent cadang + JUSTIFIKASI + citation (tiada citation → auto-tolak)
  • Human soal / bantah → agent jawab dengan bukti
  • Sebulat suara → PINTU lulus; maks 2 pusingan → eskalasi berperingkat; semua dirakam

Guardrails Statutori (P8)

  • Setiap tindakan dipetakan ke seksyen akta terverifikasi (PERLU SAHKAN disekat)
  • Diskresi kehakiman & khilaf syariah → manusia/panel
  • S7/S9 kuasa luar sistem — sistem sediakan, menjejak & merekod sahaja

Audit Trail (P6)

  • Rekod pintu: pasangan + hash input/output + asas statutori + transkrip Q&A + keputusan
  • Rantai hash tamper-evident — pengubahan silam dikesan
  • Siapa semak siapa: A8→agent · human→agent · Penyelia→pasangan · audit→semua
